OFFLINE LUDO - Android Project
1) Android Studio install karein.
2) Is ZIP ko extract karein.
3) Android Studio > Open > OfflineLudo folder select karein.
4) Gradle sync complete hone dein.
5) Build > Build Bundle(s) / APK(s) > Build APK(s).
6) app/build/outputs/apk/debug/app-debug.apk ko Android phone me install karein.

Game features: 2/4 player selection, manual dice 1-6, auto dice, offline play.
Note: Yeh initial playable prototype hai; board artwork aur rules ko aage polish kiya ja sakta hai.
